# kotlin-calculator-precourse
***
## 목적
- 입력한 문자열에서 숫자를 추출하여 더하는 계산기 구현
***
## 기능 구분
- 구분자와 숫자로 구성된 문자열 입력
- 문자열에서 구분자를 기준으로 분리한 각 숫자의 합을 출력
    - 기본 구분자 : ":", ","
    - ""을 입력받을 경우 0을 출력
- 커스텀 구분자 생성
    - 생성 방법 : 문자열 앞부분에 "//{생성할 새로운 구분자}\n" 형식 사용
- 사용자가 잘못된 값을 입력했을 때 IllegalArgumentException을 발생시킨 후 종료
***
## 예외 상황
- 커스텀 생성자의 형식을 잘못 작성한 경우
- 커스텀 생성자를 앞이 아닌 다른 부분에 작성한 경우
- 문자열에 구분자(기본 및 커스텀)와 양수가 아닌 문자가 포함된 경우
- 공백과 문자열이 아닌 값을 입력받은 경우
***
## 입출력 예시
~~~
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
~~~
